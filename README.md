# 💼 Portfólio

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades técnicas e experiência como desenvolvedor de software.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- Vite

## ✨ Funcionalidades

- Apresentação de projetos
- Seção de habilidades
- Informações profissionais
- Contato

## 📦 Como executar

Clone o repositório:

```bash
git clone https://github.com/JonasPinheiro/portfolio.git
```

Acesse a pasta:

```bash
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```
